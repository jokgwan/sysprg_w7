## 1. **프로젝트 설명**

이 프로젝트는 C 언어와 Linux 프로세스 간 통신 기능을 이용해 세 가지 과제를 실습합니다.

- **1번 과제: 1_pipe_basic.c**  : 두 개의 익명 파이프를 이용해 부모 프로세스가 문자열을 자식에게 보내고, 자식이 영문자를 대문자로 변환한 결과를 부모에게 돌려줍니다.
- **2번 과제: 2_pipe_dup2.c** : dup2()와 파이프를 이용해 두 명령어의 표준 출력과 표준 입력을 연결합니다. :을 기준으로 명령어를 구분합니다.
- **3번 과제: 3_fifo_read.c, 4_fifo_write.c** : FIFO(이름 있는 파이프)를 이용해 별도의 송신 프로그램과 수신 프로그램 사이에서 메시지를 전달합니다.

## 2. **컴파일하기!**

Ubuntu 또는 WSL에서 소스 파일이 있는 폴더로 이동한 뒤 아래 명령어를 실행합니다.

```COMPILE
gcc -Wall -Wextra -o 1_pipe 1_pipe_basic.c
gcc -Wall -Wextra -o 2_pipeline 2_pipe_dup2.c
gcc -Wall -Wextra -o 3_fifo_read 3_fifo_read.c
gcc -Wall -Wextra -o 4_fifo_write 4_fifo_write.c
```



## 3. **실행 방법**

### 1번 과제 실습

```practice
./1_pipe "hello world"
```

부모 프로세스가 입력 문자열을 자식 프로세스에 전달하고, 자식이 대문자로 변환한 문자열을 부모에게 반환하는지 확인합니다. 예를 들어 결과 문자열은 `HELLO WORLD`가 됩니다.

### 2번 과제 실습

```practice
./2_pipeline ls -l : wc -l
```

`:` 앞의 `ls -l`이 출력한 내용을 `:` 뒤의 `wc -l`에 전달합니다. 따라서 현재 디렉터리의 목록에 대한 줄 수가 출력됩니다. 출력 숫자는 디렉터리 내용에 따라 달라질 수 있습니다.

### 3번 과제 실습

이 과제는 터미널을 두 개 열어 실행합니다.

**터미널 1 — 수신 프로그램 실행:**

```practice
./3_fifo_read
```

**터미널 2 — 송신 프로그램 실행:**

```practice
./4_fifo_write "안녕하세요"
```

수신 프로그램이 메시지를 받았는지 확인합니다. FIFO의 `open()`은 반대편 프로세스가 연결될 때까지 대기할 수 있으므로 수신 프로그램을 먼저 실행합니다. 수신이 끝나면 프로그램에서 FIFO 파일을 정리합니다.

### **과제 1에 사용한 프롬프트**

C언어로 파이프를 이용해서 부모 프로세스와 자식 프로세스가 서로 데이터를 주고받는 프로그램을 만들어 줘. 부모가 입력한 문자열을 자식에게 보내고, 자식은 영어 소문자를 대문자로 바꿔서 다시 부모에게 보내게 해 줘.

### **과제 2에 사용한 프롬프트**

C언어에서 dup2()를 이용해서 두 개의 명령어를 연결하는 프로그램을 만들어 줘. 예를 들어 ls -l : wc -l을 입력하면 앞의 명령어 결과가 뒤의 명령어로 전달되게 해 줘. :을 기준으로 명령어를 구분하고, 각 코드의 설명 또한 해줘.

### **과제 3에 사용한 프롬프트**

C언어로 FIFO를 이용해서 두 프로그램이 메시지를 주고받도록 만들어 줘. 하나는 메시지를 보내고 다른 하나는 메시지를 받는 프로그램으로 작성해 줘. 메시지를 받은 뒤에는 FIFO 파일도 정리하도록 해 줘. 코드별로 이해하기 쉽게 설명도 해줘.


## 5. **본인의 보강 내용 및 변경 사항**

- **1번 과제:** 기존 코드는 지정된 문자열을 자식 프로세스에 보내는 단방향 통신이었습니다. 명령행 인자로 문자열을 입력받도록 하고, 두 번째 파이프를 추가해 자식이 대문자로 변환한 결과를 부모에게 돌려주도록 변경했습니다.
- **2번 과제:** 기존 코드는 `ls`와 `wc -l` 명령어가 고정되어 있었습니다. 콜론(`:`)을 기준으로 명령어와 인자를 나누어 실행하도록 확장하고, `dup2()`로 첫 번째 명령어의 표준 출력과 두 번째 명령어의 표준 입력을 연결했습니다.
- **3번 과제:** 기존 FIFO 송신·수신 예제의 구조를 활용해 두 프로그램을 실행하고 메시지가 전달되는지 확인했습니다. 수신 프로그램이 FIFO를 읽은 후 정리하는 과정도 확인했습니다.
- 컴파일할 때 `-Wall -Wextra` 옵션을 사용해 경고를 확인하고, 각 프로그램을 직접 실행해 동작을 점검했습니다.
- 이번 과제를 통해 파이프는 프로세스 간 데이터 전달에 사용되고, `dup2()`는 표준 입력·출력을 연결하며, FIFO는 이름이 있는 통신 경로를 제공한다는 점을 이해했습니다.
